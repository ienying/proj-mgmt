# 信息广场 — 系统提示词

> 本文档根据现有代码实现反向梳理，合并旧版（公告/资料/分享）和新版（五类文档库+视频中心）需求，可作为在其他项目中复刻该功能的提示词。

---

# 角色
你是一个全栈开发专家，精通 Next.js + React + TypeScript + PostgreSQL + S3 对象存储技术栈，同时具备知识库/文档管理系统的架构设计能力。

# 任务
实现一个名为「信息广场」的团队内部知识共享与文档管理模块。内容分类为：技术文档、产品手册、运维工具、验收资料、方案模板、视频中心。

---

## 一、模块定位

信息广场是项目团队的统一知识库，承载六类内容：

| 类型 | 定位 | 包含内容 |
|------|------|----------|
| 技术文档 | 系统技术资料 | 系统部署手册、安装部署、常见问题处理 |
| 产品手册 | 产品使用说明 | 智慧校园操作手册、软硬件说明书、硬件参数、接线图、功能说明、版本差异 |
| 运维工具 | 运维调试资源 | 调试工具、固件包、授权工具、日志抓取脚本、驱动程序 |
| 验收资料 | 项目验收文档 | 验收规范、验收记录表、竣工资料、验收PPT、问题整改方案 |
| 方案模板 | 业务方案模板 | 售前收费方案、交付单据、沟通模板 |
| 视频中心 | 产品视频资源 | 操作演示视频、培训视频、产品介绍视频 |

该模块在 Dock 导航栏中显示为「信息广场」（紫色 Megaphone 图标），并在有未读内容更新时展示角标数字。

## 二、页面结构

### 2.1 首页布局

用户进入后直接看到全部内容，无需点击展开：

```
┌──────────────────────────────────────────────┐
│              全局搜索框                        │
├──────────────────────────────────────────────┤
│  技术文档    │  产品手册    │  运维工具        │
│  方案模板    │  验收资料    │  视频中心        │
├──────────────────────────────────────────────┤
│         轮动显示最新/浏览信息                   │
└──────────────────────────────────────────────┘
```

每张卡片展示：
- 分类图标 + 名称
- 该分类下文档总数
- 简短介绍文字
- 卡片悬停上浮动效（`hover:-translate-y-2`），毛玻璃背景风格

### 2.2 全局搜索框

- 支持按**分类**进行筛选（下拉多选）
- 支持按**文件名**进行搜索
- 支持搜索**文档内容**全文匹配
- 搜索结果展示：标题、所属分类、匹配片段高亮、发布日期

### 2.3 分类列表页

点击首页卡片进入对应分类：

- **顶部**：返回按钮 + 分类标题 +「+ 发布」按钮
- **搜索栏**：分类内搜索，支持按标签/文件名/内容搜索
- **文档列表**：每条展示：
  - 标题（可点击查看详情）
  - 发布人 + 发布日期
  - 附件名称列表（文件图标 + 文件名 + 大小）
  - 版本号（v1, v2...）
  - 标签徽章
  - 浏览数 + 下载数
- **点击一次**：右侧滑出详情面板（Drawer/Sheet）
- 排序：按更新时间倒序

### 2.4 轮动浏览区

首页底部轮动展示：
- 最新发布的文档
- 热门下载排行
- 最近浏览过的文档

## 三、发布功能

### 3.1 富文本编辑器

发布/编辑时使用**全屏编辑页面**，集成 wangeditor 富文本编辑器：

**编辑模式切换**：
- 富文本模式（类似 Word）：所见即所得，支持格式化/表格/图片插入
- Markdown 模式：支持 Markdown 语法，实时预览

**从 Word 粘贴图片**：
- 配置 wangeditor 的 `uploadImage.customUpload`
- 粘贴含图片的 Word 内容时自动将图片上传到服务器，替换为预览链接

**实时目录**：
- 编辑器右上角显示「目录(N)」按钮
- 点击弹出悬浮面板，实时解析当前 h1-h4 标题层级
- 点击标题直接跳转到对应位置

**点击任意位置编辑**：
- 编辑器容器添加 `onClick` 调用 `editor.focus()`
- 点击区域任意位置即可开始输入

### 3.2 附件上传

- 支持格式：Word(.doc/.docx)、Excel(.xls/.xlsx)、PPT(.ppt/.pptx)、PDF、压缩包(.zip/.rar/.7z)
- **附件不存数据库**，存储到服务器指定目录：`./data/info-square/{分类}/`
- 数据库中仅记录文件路径元数据
- 上传时可打标签

### 3.3 附件孤儿清理机制

```
粘贴图片 → 自动上传 → 文件路径记入 orphanedFilesRef
点击保存 → 清空记录（图片已关联到文章内容中）
点击关闭/取消 → 调用 /api/knowledge/cleanup 删除所有本会话中自动上传的孤儿文件
```

### 3.4 二次编辑与版本管理

- 发布完成后支持二次编辑
- 每次编辑自动增加版本号（v1 → v2 → v3...）
- 版本历史记录存入 `knowledge_versions` 表
- 可查看历史版本并回滚

## 四、详情查看与分享

### 4.1 详情面板

点击列表中的文档，右侧滑出详情面板：
- 标题 + 版本号 + 发布人 + 日期
- 目录导航（如果编辑器中有标题层级，点击可直接跳转）
- 正文内容（富文本/Markdown 渲染）
- 附件下载区（文件图标 + 文件名 + 大小 + 下载按钮）
- 标签列表
- 操作按钮：分享 / 下载 / 编辑 / 删除

### 4.2 分享功能

每个发布后生成一个唯一分享链接：
- 点击「分享」按钮复制链接
- 链接可直接查看文档内容（无需登录）
- 支持系统外用户访问和下载附件

### 4.3 附件预览

- 支持文档类型在线预览（PDF/图片直接预览）
- 视频支持浏览器播放
- Word/Excel/PPT 支持在线预览或提示下载

## 五、下载追踪

- 用户下载附件时记录到 `knowledge_downloads` 表
- 记录：用户ID、文档ID、附件ID、下载时间
- 详情页展示下载次数统计

## 六、删除权限

- 超管和发布人可**硬删除**文档
- 删除时同时删除服务器上的附件文件
- 删除前弹确认对话框

## 七、视频中心

### 7.1 功能定位

视频中心独立于上述五类文档库，专注于视频资源管理。

### 7.2 上传

- 用户直接上传视频文件
- 视频名称从上传文件名自动读取，可手动修改
- 上传时下拉选择关联的**产品模块**（数据来源于系统设置 → 基础数据 → 产品模块）
- 可打标签

### 7.3 配套文件

视频上传时，可配套上传：
- PPT 文件
- Word 文档
- PDF 文件
- Markdown 文件
- 压缩包

### 7.4 存储

- 视频和配套文件存储到服务器目录：`./data/info-square/videos/`
- **不存数据库**，数据库仅记录路径
- 删除为**硬删除**（同时删除服务器文件）
- 创建人和超管可删除

### 7.5 查看与筛选

- 用户直接看到所有视频
- 可通过**标签**和**产品模块**筛选
- 支持在线播放
- 支持下载

### 7.6 互动

- 访问用户可留言评论
- 任何用户可回复评论
- 系统管理员可删除留言

## 十一、API 设计

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | `/api/knowledge/categories` | 获取分类列表 |
| GET | `/api/knowledge/posts?category=&tag=&search=` | 搜索/列表文档 |
| POST | `/api/knowledge/posts` | 创建文档 |
| PUT | `/api/knowledge/posts/:id` | 编辑文档（自动生成版本） |
| DELETE | `/api/knowledge/posts/:id` | 删除文档（硬删除+清理文件） |
| GET | `/api/knowledge/posts/:id` | 获取文档详情 |

| POST | `/api/knowledge/posts/:id/restore/:versionId` | 回滚到指定版本 |
| POST | `/api/knowledge/posts/:id/comments` | 发表评论 |
| DELETE | `/api/knowledge/comments/:id` | 删除评论 |
| GET | `/api/knowledge/tags` | 获取标签列表 |
| POST | `/api/knowledge/tags` | 新增标签 |
| PUT | `/api/knowledge/tags/:id` | 编辑标签 |
| DELETE | `/api/knowledge/tags/:id` | 删除标签 |

## 十二、核心交互流

```
用户进入信息广场
  ↓
[首页] 搜索框 + 六分类卡片 + 轮动浏览
  ↓ 点击分类卡片
[分类列表] 搜索 + 标签筛选 + 文档列表
  ↓ 点击文档                     ↓ 点击发布
[右侧详情面板]                [全屏编辑页面]
  ├ 查看正文/目录/附件           ├ 富文本/Markdown 编辑
  ├ 下载附件（记录追踪）          ├ 上传附件+打标签
  ├ 分享链接                    ├ 实时目录
  └ 评论/回复                   └ 保存发布（v1）
                                    ↓
                              二次编辑（v2, v3...）
```

### 13.6 交互动效

| 元素 | 动效 | 时长 |
|------|------|------|
| 首页卡片 | hover: translateY(-4px) + shadow-lg | 300ms |
| 卡片进入 | stagger fadeIn + translateY(20px→0) | 逐卡 100ms |
| 右侧面板 | slideInFromRight | 300ms |
| 搜索框聚焦 | ring 展开 + border 变色 | 200ms |
| 附件上传 | drop 区域变色 + 文件列表追加 | 200ms |
| 版本切换 | 内容区 crossFade | 300ms |
| 分享链接复制 | 按钮文字 "复制" → "已复制 ✓" | 200ms |
| 编辑器目录 | 悬浮面板 slideDown | 200ms |

### 13.7 响应式

| 宽度 | 变化 |
|------|------|
| ≥1024px | 3 列卡片 / 右侧面板 480px |
| 640-1024px | 2 列卡片 / 右侧面板 100% |
| <640px | 1 列卡片 / 全屏详情 |

### 13.8 通用规则

- 整体风格：毛玻璃卡片 + 大圆角（rounded-3xl）+ 大间距（gap-6）
- 附件不存数据库，存储到 `./data/info-square/{分类}/`
- 删除为硬删除（同时删服务器文件）
- 编辑自动生成新版本（v1→v2→v3...）
- 过渡动效统一 `transition-all duration-300`

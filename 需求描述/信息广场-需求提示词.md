# 信息广场 — 需求提示词

> 本文档根据现有代码实现反向梳理，可作为在其他项目中复刻该功能的提示词。

---

# 角色
你是一个全栈开发专家，精通 Next.js + React + TypeScript 技术栈，同时具备良好的产品交互设计能力。

# 任务
实现一个名为「信息广场」的团队内部信息共享与互动模块。

---

## 一、模块定位

信息广场是团队内部的信息中枢，承载三类内容：

| 类型 | 标识 | 定位 | 发布权限 |
|------|------|------|----------|
| 公告通知 | `announcement` | 全员公告、重要通知，需追踪已读/未读 | 管理员 |
| 共享资料 | `material` | 文档、视频等资料供团队成员查询与下载 | 管理员 |
| 经验分享 | `share` | 人人可发布的实施经验、问题解决方案、最佳实践、工具推荐 | 所有人 |

该模块在主导航栏/Dock 中显示为「信息广场」（紫色 Megaphone 图标），并在有未读公告时展示角标数字。

---

## 二、页面结构

### 2.1 首页 — 三卡片入口

用户首次进入时看到三张卡片，分别对应三类内容。每张卡片展示：

- **图标**：公告（喇叭）、资料（书本）、分享（灯泡），各有独立配色与渐变背景
- **标题**：公告通知 / 共享资料 / 经验分享
- **描述**：一句话说明该板块用途
- **内容计数**：「X 篇内容」显示该分类下的帖子总数
- **进入按钮**：点击后进入对应分类的列表视图

卡片有悬停上浮动效（`hover:-translate-y-2`），毛玻璃背景风格（`backdrop-blur`），大圆角（`rounded-3xl`）。

### 2.2 列表页

顶部布局：

- **返回按钮**：回到首页三卡片
- **Tab 切换**：三个 Tab 切换公告通知 / 共享资料 / 经验分享，选中态为白底 indigo 文字
- **发布按钮**：右侧 "＋发布" 按钮，仅管理员可见（公告通知和共享资料），经验分享所有人可见

筛选区：

- **搜索框**：关键词搜索（匹配标题 + 正文），支持回车触发搜索
- **分类下拉**：动态加载该类型下的子分类（如"制度文件""培训视频"等），由管理员在后端维护
- **媒体类型筛选**（仅共享资料 Tab 可见）：全部 / 文档 / 视频 / 其他
- **搜索按钮**：触发筛选请求

帖子卡片列表：

每条帖子展示：

- **置顶标记**：红色 Pin 图标 + 红色「置顶」徽章
- **标题**：单行截断
- **元信息**：作者 · 发布日期 · 浏览数 · 点赞数 · 评论数
- **附件预览**（共享资料）：最多展示 3 个附件标签（文档图标/视频图标 + 文件名 + 时长），超出显示 "+N 个文件"
- **分享类型徽章**（经验分享）：实施经验 / 问题解决 / 最佳实践 / 工具推荐

排序规则：置顶帖优先 → 按创建时间倒序。

空态：显示空文件夹图标 + "暂无内容"。

### 2.3 帖子详情弹窗

点击帖子卡片弹出详情对话框（Dialog，最大宽度 3xl，最大高度 85vh 可滚动）：

- **标题**：含置顶标记
- **元信息**：作者、日期、浏览量、「已读 X/Y人」（仅公告通知显示已读追踪）
- **标签列表**：多标签小徽章
- **正文**：保留换行格式的白底文本区
- **附件区**：若存在附件则逐条展示，每条含文件图标、文件名、大小、时长，支持「播放」（视频）和「下载」按钮
- **互动区**：
  - 点赞按钮（已点赞时图标实心填充 indigo）
  - 收藏按钮（已收藏时图标实心填充 amber）
  - 评论计数
- **评论区**：逐条展示评论（作者名、日期、内容），底部输入框 + 发送按钮

打开详情时自动标记该帖为已读（调用 `POST /api/knowledge/posts/:id/read`）。

## 三、发布功能

点击「发布」按钮弹出发布对话框，表单字段因类型不同：

| 字段 | 公告通知 | 共享资料 | 经验分享 |
|------|:---:|:---:|:---:|
| 标题 | ✅ | ✅ | ✅ |
| 分类选择 | ✅ | ✅ | ✅ |
| 分享类型下拉 | - | - | ✅（实施经验/问题解决/最佳实践/工具推荐） |
| 正文内容 | ✅ | ✅ | ✅ |
| 标签（逗号分隔） | ✅ | ✅ | ✅ |
| 附件上传 | ✅ | ✅ | ✅ |
| 置顶开关 | ✅ | - | - |

附件上传：

- 拖拽上传区域，支持多文件
- 列出已选文件，可逐个移除
- 支持文档、视频、压缩包等格式
- 视频上传后自动识别时长
- 后端将文件上传至 S3 兼容的对象存储

发布流程：先创建帖子记录 → 获取 post_id → 依次上传附件到 `/api/knowledge/upload` → 关联到帖子。

## 四、互动功能

### 4.1 点赞
- 调用 `POST /api/knowledge/posts/:id/like`
- 传入 `user_id`
- 后端检查是否已点赞：已点赞则取消（删除记录 + 计数 -1），未点赞则点赞（插入记录 + 计数 +1）
- 前端根据返回结果刷新 UI 状态

### 4.2 收藏
- 调用 `POST /api/knowledge/posts/:id/favorite`
- 逻辑同点赞（toggle 模式）

### 4.3 评论
- 调用 `POST /api/knowledge/posts/:id/comments`
- 传入 `content`、`author_id`、`author_name`
- 发布成功后刷新评论列表

### 4.4 已读追踪（仅公告通知）
- 用户打开公告详情时自动标记已读
- 调用 `POST /api/knowledge/posts/:id/read`
- 记录 `user_id` + `post_id` 到 `knowledge_reads` 表
- 用于角标计算：未读公告数 = 所有公告数 − 当前用户已读数

### 4.5 附件下载
- 调用 `/api/knowledge/download` 获取 S3 签名 URL
- 前端创建隐藏 `<a>` 标签触发浏览器下载

## 五、角标（Badge）系统

主导航上信息广场的角标数字 = 当前用户未读的公告通知数量。

计算方式：

1. 查询全部启用的公告帖子（`post_type = 'announcement'`）
2. 查询 `knowledge_reads` 表中当前 `user_id` 的所有已读记录
3. 未读数 = 总公告数 − 已读数（按 user_id + post_id 去重）

角标在用户打开公告详情时实时更新（前端状态刷新 + 重新请求 badges API）。

## 六、分类管理（系统设置集成）

在系统设置页面中增加「信息广场分类维护」面板，提供：

- **分类列表**：按类型分组（公告通知 / 共享资料 / 经验分享），显示名称、图标、排序号、启用状态
- **新增分类**：填写名称 → 选择图标（14 种 Lucide 图标可选）→ 选择所属类型 → 自动分配排序号
- **编辑分类**：点击编辑按钮修改名称、图标、类型
- **删除分类**：确认后删除
- **启用/禁用**：切换开关控制该分类是否在前端展示
- **排序**：同类型内支持上移/下移（交换排序号）
- 图标选项：Folder、Megaphone、FileText、RefreshCw、GraduationCap、BookOpen、Compass、Video、Wrench、Lightbulb、CheckCircle、Award、ThumbsUp、Star

## 七、数据库设计

### 7.1 表结构

**knowledge_categories**（分类表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| name | text | 分类名称 |
| category_type | text | 所属类型：announcement / material / share |
| icon | text | Lucide 图标名称 |
| sort_order | integer | 排序号（同类型内排序） |
| is_enabled | boolean | 是否启用 |

**knowledge_posts**（帖子表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| title | text | 标题 |
| content | text | 正文 |
| post_type | text | 类型：announcement / material / share |
| category_id | uuid | 外键 → knowledge_categories |
| share_type | text | 分享类型（仅 share 类型）：experience / solution / best_practice / tool |
| author_id | uuid | 作者用户 ID |
| author_name | text | 作者名称（冗余） |
| is_pinned | boolean | 是否置顶 |
| tags | text[] | 标签数组 |
| is_enabled | boolean | 是否启用（软删除） |
| view_count | integer | 浏览次数 |
| like_count | integer | 点赞数（冗余计数） |
| comment_count | integer | 评论数（冗余计数） |
| created_at | timestamptz | 创建时间 |
| updated_at | timestamptz | 更新时间 |

**knowledge_attachments**（附件表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| post_id | uuid | 外键 → knowledge_posts |
| file_name | text | 文件名 |
| file_url | text | S3 存储路径 |
| file_size | integer | 字节数 |
| file_type | text | 文件 MIME 类型 |
| media_type | text | 媒体分类：document / video / other |
| duration | integer | 视频时长（秒），非视频为 null |

**knowledge_reads**（已读记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| post_id | uuid | 外键 → knowledge_posts |
| user_id | uuid | 用户 ID |
| created_at | timestamptz | 阅读时间 |

**knowledge_likes**（点赞记录表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| post_id | uuid | 外键 → knowledge_posts |
| user_id | uuid | 用户 ID |
| action_type | text | 固定为 'like' |

**knowledge_comments**（评论表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| post_id | uuid | 外键 → knowledge_posts |
| parent_id | uuid | 父评论 ID（预留，暂未启用） |
| author_id | uuid | 评论者用户 ID |
| author_name | text | 评论者名称（冗余） |
| content | text | 评论内容 |
| created_at | timestamptz | 创建时间 |

### 7.2 设计要点

- `like_count`、`comment_count` 采用冗余计数字段，避免频繁 JOIN 查询
- `is_enabled` 字段实现软删除/禁用，查询时需过滤 `is_enabled !== false`
- 附件通过 S3 兼容对象存储，数据库仅存路径指针
- 分类表与帖子表通过 `category_type` 字段对齐，而非仅靠外键 —— 这样前端可快速筛选同类型下的分类

## 八、核心交互流

```
用户进入信息广场
  ↓
[首页] 三卡片入口，显示各类别帖子数
  ↓ 点击卡片
[列表页] Tab 切换 + 搜索/筛选 + 帖子列表
  ↓ 点击帖子          ↓ 点击发布按钮
[详情弹窗]           [发布弹窗]
  ├ 浏览正文           ├ 填写表单
  ├ 下载附件           ├ 上传附件
  ├ 点赞/收藏          └ 提交 → 刷新列表
  ├ 评论
  └ 自动标记已读
```

## 十、UI/UX 规范

- 整体风格：毛玻璃卡片（`backdrop-blur` + 半透明白底）+ 大圆角（`rounded-3xl`）
- 配色体系：
  - 公告通知：amber/orange 暖色系
  - 共享资料：blue/indigo 冷色系
  - 经验分享：emerald/green 清新系
  - 信息广场图标：purple（紫色 Megaphone）
- 过渡动效：`transition-all duration-300/500`，悬停上浮 + 阴影加深
- 响应式：首页三卡片在小屏下堆叠为单列
- 加载态：居中显示「加载中...」占位文字
- 空态：置灰图标 + 简要说明文字

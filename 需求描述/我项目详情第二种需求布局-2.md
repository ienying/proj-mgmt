方案：阶段日期时间设置
一、规范管理中新增设置
在编辑表时，增加一个「阶段日期绑定」区域：

设置项	操作
计划开始时间列	下拉选择表中一个日期列
计划完成时间列	下拉选择表中一个日期列
实际开始时间列	下拉选择表中一个日期列（可选）
实际完成时间列	下拉选择表中一个日期列（可选）
二、阶段式布局显示效果
步骤条日期显示：


┌─────────┬─────────┬─────────┐
│   ①    │   ②    │   ③    │
│ 启动    │ 调研    │ 部署    │
│02.20-  │03.01-  │03.21-  │
│02.28   │03.20   │04.15   │   ← 计划日期
│        │        │⚠03.25  │   ← 实际超期
└─────────┴─────────┴─────────┘
每个阶段圆圈下方显示该阶段的日期范围：

只有计划时间 → 显示一行 02.20 - 02.28
有计划+实际时间 → 显示两行，计划灰色，实际蓝色
实际晚于计划 → 实际日期标红 + ⚠ 图标
阶段详情区：

左侧阶段信息卡片下方增加日期对比：


┌ 计划周期：2026.02.20 — 2026.02.28 (9天)
│ 实际周期：2026.02.21 — 2026.03.02 (10天)  ⚠ 延期2天
└ 完成率：100%
三、日期计算逻辑
系统自动读取该阶段关联的所有表中的绑定列：

计算项	取值方式
计划开始	所有记录中「计划开始时间列」的最小值
计划结束	所有记录中「计划完成时间列」的最大值
实际开始	所有记录中「实际开始时间列」的最小值
实际结束	所有记录中「实际完成时间列」的最大值
是否延期	实际结束 > 计划结束 → 红色标记
进度偏差	(实际结束 - 计划结束) 天数
四、操作流程
规范管理 → 编辑表 → 找到「阶段日期绑定」
下拉选择四个日期列（至少选计划开始和计划结束）
保存
进入阶段式布局 → 步骤条自动显示日期 → 阶段详情显示日期对比



步骤条日期：每个阶段圆形下方显示 2026.03.01 — 2026.03.31 格式日期，延期显示红色 ⚠
左列日期：改为 2026.02.20 — 2026.02.28 格式
图标：📅→日历 SVG，🕐→时钟 SVG，扁平化风格
颜色：计划灰色，实际黑色，延期红色

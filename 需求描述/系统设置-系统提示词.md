# 系统设置 — 系统提示词

> 本文档根据现有代码实现反向梳理，汇总跨模块的管理配置功能，可作为在其他项目中复刻该功能的提示词。

# 角色
你是一个全栈开发专家，精通 Next.js + React + TypeScript + PostgreSQL 技术栈，同时具备企业级管理后台的架构设计能力。

# 任务
实现「系统设置」模块——平台级配置管理中心，为其他所有模块提供基础数据、字典配置、权限策略等支撑。

## 一、模块定位

系统设置是平台的**配置中枢**，在 Dock 导航栏以齿轮图标呈现。所有模块的共用配置均在此维护。

核心职责：
1. **基础数据管理**：字典表（项目类型/阶段/状态/部门/部署模式/客户类型/学校类型）
2. **产品模块管理**：产品线 → 模块树形结构
3. **用户与权限管理**：用户管理、角色管理
4. **大模型配置**：DeepSeek API Key + 模型选择（详见 [AI功能-系统提示词](AI功能-系统提示词.md)）
5. **信息广场分类维护**：分类 + 标签管理（详见 [信息广场-系统提示词](信息广场-系统提示词.md)）
6. **工单配置**：外部工单接收人指定
7. **项目模块启用配置**：类型×阶段 二维矩阵
8. **Schema 自动匹配规则**：规范表自动复制规则
9. **AI 使用统计**：全平台 AI 调用排行榜（详见 [AI功能-系统提示词](AI功能-系统提示词.md)）

## 三、基础数据管理

### 3.1 概述

基础数据（字典表）为全局下拉选择提供数据源。所有字典表采用统一的数据结构：

```sql
CREATE TABLE design_public.dict_xxx (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  sort_order INTEGER DEFAULT 0,
  is_enabled BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.2 字典项列表

| 字典 | 表名 | 使用场景 |
|------|------|----------|
| 项目类型 | `project_types` | 项目创建/筛选、模块启用配置 |
| 项目阶段 | `project_stages` | 项目创建/筛选、模块启用配置 |
| 项目状态 | `project_statuses` | 项目筛选、看板筛选 |
| 部门 | `departments` | 项目创建/筛选、成员管理 |
| 部署模式 | `deployment_modes` | 项目创建/筛选 |
| 客户类型 | `customer_types` | 项目创建/筛选、画像管理 |
| 学校类型 | `school_types` | 画像创建（幼儿园/小学/初中/中职/高中/高职/技师/教育局） |

### 3.3 交互设计

每个字典项的管理界面：


## 四、产品模块管理

### 4.1 概述

产品模块为树形结构：产品线 → 产品 → 模块（三级或二级）。数据来源为案例中心画像中的模块匹配和项目采购模块选择。

### 4.2 数据表

```sql
CREATE TABLE design_public.product_modules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  parent_id UUID REFERENCES product_modules(id),  -- null = 产品线
  code TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,               -- 前端中文名称
  level INTEGER DEFAULT 1,          -- 1=产品线, 2=产品, 3=模块
  sort_order INTEGER DEFAULT 0,
  is_enabled BOOLEAN DEFAULT true,
  description TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

| 启用/禁用 | Toggle | 禁用后前端下拉不展示该模块 |
| 拖拽排序 | ⠿ grip | 拖拽到目标位置，同层级内排序 |
| 拖拽移动 | ⠿ grip | 拖拽到其他父级下，改变 parent_id 和 level |

**批量导入**（可选）：
- [📥 导入] 按钮：下载模板 Excel → 填写后上传 → 预览 → 确认导入
- Excel 模板列：父级编码、模块名称、模块编码、层级、排序号、描述

## 五、项目管理模块定义

### 5.1 概述

定义项目管理中的 10 大管理模块（范围/进度/质量/成本/协同/沟通/风险/采购/资源/资料）。这些模块决定了项目详情页的 Tab 栏和每个项目的数据表分组。管理员可手动增删改。

与「产品模块」（第四章）的区别：
- **产品模块**：面向客户的业务产品目录（如智慧校园→教务管理→课表中心），用于画像匹配和采购
- **管理模块**：面向项目管理的 PMBOK 知识领域（如范围管理、进度管理），用于项目详情 Tab

### 5.2 数据表

```sql
CREATE TABLE design_public.project_modules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  code TEXT UNIQUE NOT NULL,              -- scope / schedule / quality ...
  name TEXT NOT NULL,                     -- 范围管理 / 进度管理 / 质量管理 ...
  icon TEXT NOT NULL,                     -- Lucide 图标名称: Target / TrendingUp ...
  color TEXT NOT NULL,                    -- 主题色: #3b82f6 / #10b981 ...
  description TEXT,                       -- 模块功能描述
  sort_order INTEGER DEFAULT 0,           -- Tab 栏从左到右排序
  is_default BOOLEAN DEFAULT false,       -- 是否默认模块（默认10个受保护）
  is_enabled BOOLEAN DEFAULT true,        -- 是否启用
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 5.3 种子数据（10 个默认模块，is_default=true）

| code | name | icon | color | sort |
|------|------|------|-------|:--:|
| scope | 范围管理 | Target | #3b82f6 | 1 |
| schedule | 进度管理 | TrendingUp | #10b981 | 2 |
| quality | 质量管理 | Check | #8b5cf6 | 3 |
| cost | 成本管理 | DollarSign | #f59e0b | 4 |
| collaboration | 协同管理 | Users | #06b6d4 | 5 |
| communication | 沟通管理 | MessageSquare | #ec4899 | 6 |
| risk | 风险管理 | Shield | #ef4444 | 7 |

| resource | 资源管理 | Briefcase | #14b8a6 | 9 |
| document | 资料管理 | Archive | #6366f1 | 10 |

默认模块 `is_default=true`，受保护不可删除（类似 Prompt 模板的默认保护机制）。

**关键规则**：

| 规则 | 说明 |
|------|------|
| 默认模块保护 | `is_default=true` 的 10 个模块，前端删除按钮隐藏 + API 返回 403 |

| 颜色点选 | 10 种预设色 + 自定义 hex 输入框 |
| 排序影响 | sort_order 决定项目详情页 Tab 栏从左到右的顺序 |
| 禁用影响 | 禁用后项目详情页不显示该 Tab，但已有数据保留 |
| 删除保护 | 默认模块不可删；自定义模块若被项目引用 → 提示 "该模块已被 N 个项目使用，删除后相关 Tab 将隐藏" |

## 九、Schema 自动匹配规则

### 8.1 概述

配置项目创建时，规范表自动复制到项目 Schema 的匹配规则。

### 8.2 数据表

```sql
CREATE TABLE design_public.project_schema_rules (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  rule_type TEXT NOT NULL,          -- 'type_stage' | 'module' | 'direct'
  rule_name TEXT,
  project_type TEXT,                -- null = 不限
  project_stage TEXT,               -- null = 不限
  project_status TEXT,              -- null = 不限
  module_codes TEXT[],              -- 模块 code 数组 (rule_type='module')
  apply_project_types TEXT[],       -- 直接匹配的项目类型 (rule_type='direct')
  apply_project_stages TEXT[],      -- 直接匹配的项目阶段 (rule_type='direct')
  table_definitions TEXT[] NOT NULL, -- 需复制的规范表 code 数组
  is_enabled BOOLEAN DEFAULT true,
  sort_order INTEGER DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 8.3 匹配优先级

项目创建时按以下顺序匹配（由高到低）：

1. **类型+阶段精确匹配**：`project_type` + `project_stage` 都匹配
2. **类型匹配**：仅 `project_type` 匹配（stage=null）
3. **阶段匹配**：仅 `project_stage` 匹配（type=null）
4. **通用规则**：type=null, stage=null
5. **模块规则**：按采购模块交集匹配
6. **直接匹配**：`apply_project_types` / `apply_project_stages` 字段交集
7. **模块配置匹配**：通过 `project_type_stage_modules` 二维矩阵

### 8.4 交互设计

新增/编辑规则弹窗：
- 规则名称
- 规则类型：下拉选择 type_stage / module / direct

- module 类型：选择采购模块（多选）
- direct 类型：选择项目类型（多选）、选择项目阶段（多选）
- 复制规范表：从规范表列表中选择（多选，搜索+全选）
- 排序号

## 十三、UI 设计规范

### 12.1 整体布局

- 左侧深色固定侧边栏（220px，`bg-slate-900`），右侧内容区可滚动
- 菜单项：图标(18px) + 文字(14px) + 右箭头(折叠展开)
- 当前选中菜单：`bg-indigo-600/20 text-indigo-400` + 左侧 3px indigo 指示条

### 12.5 响应式

| 宽度 | 变化 |
|------|------|
| ≥1024px | 侧边栏 220px + 内容区 |
| 640-1024px | 侧边栏折叠为图标模式 60px |
| <640px | 侧边栏隐藏，顶部汉堡菜单 |

### 12.6 通用规则

- 所有删除操作需 confirm 确认
- 字典项编码（code）创建后不可修改

- 数据操作有 toast 反馈 (sonner)
- 配置变更即时生效，无需重启

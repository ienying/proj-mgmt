## 四、计算公式与数据来源

### 4.1 6 项 KPI

| KPI | 数据来源表 | 计算方式 |
|-----|-----------|----------|
| 项目总数 | 项目主表 | 统计项目数量；单项目模式下切换为客户类型字段 |
| 需求总数 | 需求登记表 | `COUNT(需求表)` |
| 高风险残留 | 风险登记表 | `COUNT(优先级="高" AND 状态≠"已关闭")` |
| 任务总数 | 任务跟踪表 | `COUNT(任务表)` |
| 干系人 | 沟通计划表 | `SUM(干系人数量)` |
| 采购项 | 采购计划表 | `SUM(采购条目)` |

### 4.2 9 大领域

| 领域 | 来源表 | 公式 |
|------|--------|------|
| 范围 | 范围管理表 | `= 已确认模块数 / 模块总数 × 100%` |
| 进度 | 进度管理表 | `= 已完成任务数 / 任务总数 × 100%` |
| 质量 | 质量管理表 | `= 通过检查点数 / 检查点总数 × 100%` |
| 成本 | 成本管理表 | `= 已付金额 / 合同总额 × 100%` |
| 沟通 | 沟通管理表 | `= 沟通记录数 / 计划次数 × 100%` |
| 风险 | 风险管理表 | `= 已关闭风险数 / 风险总数 × 100%` |
| 采购 | 采购管理表 | `= (自研到+物联到+合作商到) / (自研总+物联总+合作商总) × 100%` |
| 资源 | 资源管理表 | `= (人员到位% + 服务器到位% + 设备到位% + 账号到位%) / 4 × 100%` |
| 资料 | 资料管理表 | `= 已完成文档数 / 文档总数 × 100%` |

### 4.3 需求追踪

| 指标 | 来源表 | 计算方式 |
|------|--------|----------|
| 需求总数 | 需求登记表 | 总行数 |
| 完成率 | 需求登记表 | `状态="已完成" / 总数 × 100%` |
| 开发中 | 需求登记表 | `状态="开发中"` 计数 |
| 待确认 | 需求登记表 | `状态="待确认"` 计数 |
| 积压需求 | 需求登记表 | 等同于开发中 |
| 平均处理周期 | 需求登记表 | `AVG(完成日期 - 提出日期)` 天数 |
| 完成速率 | 需求登记表 | `已完成数 / 活跃月数` |
| 累计趋势 | 需求登记表 | 按月分组统计累计已完成数 |
| 状态分布 | 需求登记表 | 按状态字段分组统计 |
| 分类分布 | 需求登记表 | 按分类字段分组统计 |

## 五、KPI 统一配置系统

### 5.1 功能概述

每个 KPI 指标卡片右上角显示齿轮按钮（⚙️，26px 圆形），hover 旋转 60 度。点击弹出配置对话框，超管用户可以自定义该 KPI 的数据来源和计算方式。

### 5.2 配置对话框

点击齿轮 → 弹出公式说明弹窗（等宽字体公式 + 数据来源表名），包含：

- **筛选条件配置**：选择模块 → 选择数据表 → 选择列 → 设置筛选条件（支持包含/排除，支持多选）
- **多表达式运算**：支持两个子表达式的加减乘除运算。例如"高风险残留" = 表达式 A（高风险所有记录）- 表达式 B（已完成的记录）
- **导出 Excel**：支持将 KPI 数据导出

### 5.3 筛选条件

- 包含条件：选择列 → 选择操作符（等于/包含/大于/小于）→ 选择值
- 排除条件：同上逻辑
- 支持多条件组合（AND/OR）
- 多选值支持（如状态 IN ['开发中', '待确认']）

### 5.4 领域指标可配置

每个领域指标同样支持齿轮配置，超管可自定义数据来源和计算公式。

## 六、AI 预警系统

### 6.1 功能入口

页面顶部新增「生成新预警」按钮。

### 6.2 后端处理流程

```
POST /api/projects/dashboard-warnings
  → 遍历每个项目的 schema
  → 查 information_schema.tables 获取表列表
  → 逐表 COUNT(*) 获取行数
  → 拼成项目摘要文本
  → 发给 DeepSeek 分析
  → 解析 JSON 数组 [{"project_id":"...","level":"error","message":"..."}]
  → 存入 dashboard_ai_warnings 表
  → 前端渲染红/橙/蓝三色预警卡片
```

### 6.3 单指标阈值预警

| 预警项 | 触发条件 | 严重级别 | 数据来源 |
|--------|----------|----------|----------|
| 领域完成率过低 | 任意领域 < 60% | 严重 | 9大领域表 |
| 领域完成率偏低 | 任意领域 60-75% | 警告 | 9大领域表 |
| 高风险残留超限 | 高风险数 ≥ 3 项 | 严重 | 风险登记表 |
| 高风险残留存在 | 高风险数 1-2 项 | 警告 | 风险登记表 |
| 里程碑延迟 | 里程碑完成率 < 70% | 严重 | 进度管理表 |
| 回款滞后 | 回款率 < 60% | 警告 | 成本管理表 |
| 文档缺失 | 必须归档缺失 ≥ 5 项 | 严重 | 资料管理表 |
| 需求积压 | 开发中需求 ≥ 总数40% | 警告 | 需求登记表 |
| 待确认堆积 | 待确认 ≥ 5 条且超过7天 | 警告 | 需求登记表 |
| 沟通不足 | 干系人覆盖率 < 80% | 警告 | 沟通计划表 |

### 6.4 趋势恶化预警

| 预警项 | 计算方式 | 严重级别 |
|--------|----------|----------|
| 需求积压增长 | 连续2个月开发中数量上升 | 警告 |
| 完成速率骤降 | 本月完成速率 < 上月70% | 严重 |
| 风险不降反增 | 本月高风险数 > 上月 | 严重 |
| 多领域下滑 | 3个以上领域同时下降 > 5% | 严重 |
| 需求老化 | 某需求待确认超过30天 | 警告 |

### 6.5 差值/对比预警

| 预警项 | 计算方式 | 触发条件 |
|--------|----------|----------|
| 项目间严重分化 | 两项目综合得分 | 差距 > 15% |
| 项目间领域分化 | 同一领域两项目差值 | > 20% |
| 部门需求集中 | 某部门需求占比 | > 50% |

### 11.7 通用规则

- 圆角统一 10px（卡片）/ 8px（领域格）/ 6px（进度条）
- 阴影统一 `0 2px 8px rgba(0,0,0,.04)`
- 间距统一 10px gap
- 所有数据卡片使用渐变背景 + 彩色 ::before 竖线
- 数值颜色按阈值三档：绿(≥90%) / 黄(70-90%) / 红(<70%)
- Chart.js 全局配置：color #5f6570, borderColor #dde0e8

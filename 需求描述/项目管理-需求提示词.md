# 项目管理 — 需求提示词

> 本文档根据现有代码实现反向梳理，可作为在其他项目中复刻该功能的提示词。

---

# 角色
你是一个全栈开发专家，精通 Next.js + React + TypeScript + PostgreSQL 技术栈，同时具备企业级项目管理系统的架构设计能力。

# 任务
实现一个名为「项目管理」的完整项目生命周期管理模块。

---

## 一、模块定位

项目管理模块是整个平台的中枢，负责管理项目的全生命周期：

1. **项目创建**：填写项目基本信息、客户信息、渠道信息、采购模块，自动生成隔离的项目数据 Schema
2. **项目列表**：多维筛选、阶段侧边导航、列表/卡片双视图切换、CSV 导出
3. **项目详情**：10 大管理模块（对标 PMBOK 知识领域），每个模块下挂载多个数据表，支持多种视图
4. **成员与权限**：精细粒度的项目级权限控制（8 项权限）

该模块在主导航栏 Dock 中显示为「项目管理」（蓝色 FolderKanban 图标）。

### 3.2 实时预览面板

右侧固定 440px 宽面板，实时同步表单数据，分区展示：
基本信息、时间信息、客户信息（含位置/照片/联系人）、渠道信息、项目成员（Badge）、采购信息（金额 + 模块 Badge）、系统信息、对接信息

### 3.3 提交逻辑

1. 前段校验必填项（名称/编号/类型/阶段/至少一个采购模块）
2. 项目编号唯一性校验（小写英文+数字+下划线格式）
3. 项目编号重复时 toast 提示"项目编号已存在"
4. 创建成功后自动：
   - 生成项目 Schema（命名规则：`yuansu_{project_code}`）
   - 按规则匹配并复制规范表到项目 Schema
   - 为含 `procurement_record` 类型列的表自动生成采购模块记录行
   - 插入项目成员记录
5. 编辑模式下，若项目类型或阶段变更，弹出确认对话框提示影响：
   - 模块 Tab 将根据新配置刷新
   - 匹配新类型/阶段的规范表将自动创建到项目 Schema
   - 已有数据不会被删除
   - 不再启用的模块 Tab 隐藏但数据保留

### 4.3 数据表展示

每个模块下挂载若干数据表（来自规范表定义），每张表独立展示为一张卡片：

- **表头**：渐变色背景 + 白色文字（表中文名 + 行数统计）
- **工具栏**：视图模式切换 + 新增按钮（可选）

### 4.4 9 种数据视图模式

所有视图配置持久化到 localStorage（按表 Code 分组）：

#### a. 表格视图（compact）
- 标准表格布局，可自定义冻结列数和冻结行数
- 列宽可拖拽调整（持久化存储）
- 单元格点击进入编辑态：
  - 文本：Input 内联编辑
  - 单选/下拉：Select 或 RadioGroup 直接选
  - 多选：Checkbox 组
  - 采购模块选择：带搜索的 Portal 下拉弹窗，单选/多选模式
  - 文件上传（office/pdf/md/image/archive）：FileUploadField 组件
  - 视频上传：VideoUploadField 组件（支持多文件/大小限制）
  - 日期：date input
  - 只读列：灰色显示"(只读)"标记
- 编辑态操作：✓ 确认 / ✕ 取消，支持 Enter/Escape 快捷键
- 行操作：删除（需确认），数据来源为 manual 的才允许删除

#### b. 卡片视图（card）
- 每行一张卡片，可配置显示字段（Popover 勾选）
- 默认显示全部字段

#### c. 看板视图（kanban）
- 按配置的看板字段（单选/下拉类型）分列
- 卡片在列间按该字段值分组
- 可配置卡片上显示的字段

#### d. 树形视图（tree）
- 最多 4 级节点层级，每级配置一个分组字段
- 未设级别的字段在最后一级横向展示
- 点击展开/折叠

#### e. 表单视图（form）
- 单条记录浏览模式，左右箭头翻页

#### f. 甘特图视图（gantt）
- 可配置：计划开始/结束日期字段、实际开始/结束日期字段
- 时间刻度：日/周/月三种
- 可配置分组字段和进度字段
- 延期部分标红

#### g. 分组视图（group）
- 支持多级分组字段（动态添加/删除/排序）
- 可配置分组内显示的字段
- 点击分组头展开/折叠

#### h. 色标脉络视图（trace）
- 配置项：分组字段（必填）、分支字段（必填）、主行字段（最多 3 个）、串联字段（多个，可排序）
- 值相同的记录归为一组 → 值不同的成为组内并行线 → 按串联字段顺序形成节点流
- 每个串联列有独立色标（从彩色调色板循环）

#### i. 进度条视图（progress）
- 复用色标脉络配置结构
- 适用于展示进度信息

### 4.5 内联编辑

- 点击单元格进入编辑态
- 根据列类型渲染不同的编辑控件（Input/Select/Checkbox/RadioGroup/FileUpload/VideoUpload）
- 保存后立即 `PUT /api/project-data` 更新
- 只读列不可编辑

### 4.6 新增记录

- 弹出新增对话框，动态渲染所有字段的表单
- 支持引用选择器：从其他表选取记录并自动填充到当前行的对应列

### 4.7 引用关系

- 数据表间可配置双向引用关系（`references_config`）
- 自动同步：通过 `/api/project-data/sync-references` 触发双向数据同步
- 引用列以只读方式展示，值来自源表

### 4.8 关联流程任务

- 每行数据可关联任务中心的流程任务
- 通过 `source_type=project_data` 关联
- 在行内显示关联的任务定义名称

## 六、数据 Schema 隔离

### 6.1 核心设计

每个项目创建独立的 PostgreSQL Schema（`yuansu_{project_code}`），实现项目间数据完全隔离。

### 6.2 Schema 生成逻辑

项目创建时自动执行：

1. 创建 Schema：`CREATE SCHEMA IF NOT EXISTS yuansu_{project_code}`
2. 按规则匹配规范表：
   - **类型+阶段精确匹配** → **类型匹配**（stage=null） → **阶段匹配**（type=null） → **通用规则**（type=null, stage=null）
   - **模块规则**（按采购模块交集匹配）
   - **直接匹配**（`apply_project_types` / `apply_project_stages` 字段交集）
   - **模块配置匹配**（通过 `project_type_stage_modules` 二维矩阵）
3. 在项目 Schema 中 `CREATE TABLE IF NOT EXISTS`（IF NOT EXISTS 保证只增不删）
4. 复制数据：从 `design_public.std_definition_{table_code}` 复制规范数据
5. 为含 `procurement_record` 列的表自动插入采购模块记录行（按模块排序，自动匹配列名填充）

### 6.3 统一表结构

每个动态表额外包含系统字段：

| 系统字段 | 类型 | 说明 |
|----------|------|------|
| id | UUID PK | gen_random_uuid() |
| sort_order | INTEGER | 排序号，默认 0 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| created_by | VARCHAR(36) | 创建人 |
| allow_delete | BOOLEAN | 是否允许删除，默认 true |
| data_source | TEXT | 数据来源：standard / manual / procurement_module |
| _module_code | VARCHAR(255) | 采购模块隐藏列（仅 procurement_record 表） |

## 八、核心交互流

```
用户进入项目管理
  ↓
[项目列表页] 筛选 + 视图切换
  ├ 点击项目 → 右侧详情面板（概览 + 成员权限）
  ├ 点击"详情" → 进入项目详情页
  ├ 点击"新建" → 全屏创建表单 → 自动生成 Schema
  ├ 点击"导出" → CSV 下载
  └ 阶段导航 → 快速筛选
        ↓
[项目详情页] 左侧模块 Tab + 数据表
  ├ 切换模块 Tab（10 大管理领域）
  ├ 切换视图模式（9 种）
  ├ 内联编辑单元格
  ├ 新增/删除记录
  └ 关联流程任务
        ↓
[成员权限] 添加成员 → 勾选 8 项权限 → 即时生效
```

## 九、UI/UX 规范

- 整体风格：项目列表采用白底圆角卡片 + 浅灰背景
- 10 大模块各有独立渐变色头部（`bg-gradient-to-r from-{color}-500 to-{color}-600`）
- 状态标签：4 种样式 — 进行中（蓝）/ 已完成（绿）/ 已暂停（琥珀）/ 已逾期（红）
- 创建表单：8 种 Section 主题色（蓝/紫/绿/indigo/粉/青/琥珀/灰/橙），输入框聚焦有对应色环
- 视图切换按钮组：`bg-slate-100/80` 圆角底 + 选中白底阴影
- 所有视图配置持久化到 localStorage
- 数据操作有 toast 反馈（sonner）
- 删除操作需 confirm 确认

# 项目详情页 · AI 生成提示词 

> 严格按以下规范生成单文件 HTML 页面。目标是完整复刻页面视觉风格、配色、布局和交互——给另一个 AI 看完就能一模一样的产出。
>
> ⚠️ Dock 栏不需要写（系统自带），其余全部照做。

---

## 前导：关键说明（AI 必须遵守）

### 1. 外观严谨，严格复刻
页面视觉必须精确还原：所有 CSS 变量、字体大小、间距、颜色、边框、hover 效果、过渡动画——照抄，不自行发挥。

### 2. 数据来源策略
- **优先使用系统数据**：项目数据（Hero 统计、产品清单、任务列表、子页面表格等）由规格管理创建的数据表提供，AI 需定义好数据结构字段格式和渲染函数，数据的具体值由系统在运行时注入。
- **数据不可得时写静态模拟数据**：如果某些表格数据找不到对应来源，则先写静态模拟数据占位，保证页面可正常预览，后续逐步替换为真实数据。

### 3. 原有项目创建逻辑必须保留
以下交互行为不可删除或改变：
- 点击 Phase Stepper 切换阶段时，`switchPhase(idx)` 函数渲染对应阶段的详情（左侧元信息 + 右侧任务清单）
- 阶段详情中的任务点击后展开下方任务详情区（表格视图可切换）
- 数据表操作（如 CSV 导出、配置字段）逻辑完整保留

### JS 逻辑

```javascript
let activeLayout = 'phase'; // 'phase' = 阶段式, 'manage' = 管理式

function showLayoutDialog() {
  // 创建弹窗 DOM
  // 两个选项: data-layout="phase" (默认 selected) 和 data-layout="manage"
  // 点击选项切换 selected
  // 点击确定按钮: 关闭弹窗 → 根据 activeLayout 切换显示
}

function switchLayout(layout) {
  activeLayout = layout;
  if (layout === 'phase') {
    // 显示: hero + stepper + phase-detail + pd-section
    document.querySelectorAll('.phase-layout').forEach(el => el.style.display = '');
  } else {
    // 显示: hero + 8 领域管理面板（管理式布局内容）
    document.querySelectorAll('.phase-layout').forEach(el => el.style.display = 'none');
  }
}
```

### 关于管理式布局（旧版）

管理式布局是**已有的旧版布局**，不需要在本提示词中重新描述或实现。它已经存在，用户早已在使用。本提示词的目的是生成**阶段式布局（新版）**。

弹窗的作用只是让用户在进入项目详情时选择要看哪个版本——旧版管理式或新版阶段式。两套布局需共用同一套数据源（`taskData` / `subContentData` / `panelData`），切换布局不破坏数据一致性。

> 阶段式布局的完整 CSS / HTML / JS 描述见下文第 〇 到十七章节；管理式布局不需要写。

### 2.3 JS 行为

8 个 L1 项绑定 `mouseenter` 事件：
- 切换 active 态
- 从 `panelData` 对象取对应子项数据
- 填充 `#stripL2`：标题 + 子项列表（带 data-key / data-label 属性）
- 子项点击通过事件委托触发 `showSubContent(key, label)`

无需定时器、无需手动关闭——CSS `:hover` 自动折叠。

### 13.3 JS 逻辑

```javascript
function showSubContent(key, label) {
  const area = document.getElementById('subContentArea');
  const d = subContentData[key];
  if (!d) { alert('内容建设中: ' + label); return; }

  // 统计数据计算
  const total = d.rows.length;
  const confirmed = d.rows.filter(r => r.status === '已确认').length;
  const highCount = d.rows.filter(r => r.priority === '高').length;

  // 生成表格行：优先级映射 high/medium/low，状态映射 done/active/pending
  const rowsHtml = d.rows.map(r => {
    const pc = r.priority === '高' ? 'high' : (r.priority === '中' ? 'medium' : 'low');
    const sc = r.status === '已确认' ? 'done' : (r.status === '评审中' ? 'active' : 'pending');
    const sl = r.status === '已确认' ? '已完成' : (r.status === '评审中' ? '进行中' : '待开始');
    return `<tr>
      <td style="font-family:var(--font-mono);font-size:11px;color:var(--text-muted)">${r.id}</td>
      <td style="font-weight:600">${r.name}</td>
      <td><span class="sc-priority ${pc}">${r.priority}</span></td>
      <td><span class="te-status ${sc}">${sl}</span></td>
      <td>${r.owner}</td>
      <td style="font-family:var(--font-mono);font-size:11px">${r.date}</td>
      <td>${r.desc}</td>
    </tr>`;
  }).join('');

  // 渲染整个子页面
  area.innerHTML = `
    <div class="sc-hero">
      <div class="sc-hero-top">
        <button class="sc-back-btn" onclick="closeSubContent()">← 返回项目主页</button>
        <span class="sc-hero-label">${d.section}</span>
      </div>
      <h2>${label}</h2>
      <div class="sc-hero-sub">项目需求登记与跟踪管理</div>
      <div class="sc-stats">
        <div class="sc-stat-card"><span class="sc-stat-val">${total}</span><span class="sc-stat-lbl">需求总数</span></div>
        <div class="sc-stat-card"><span class="sc-stat-val green">${confirmed}</span><span class="sc-stat-lbl">已确认</span></div>
        <div class="sc-stat-card"><span class="sc-stat-val accent">${highCount}</span><span class="sc-stat-lbl">高优先级</span></div>
        <div class="sc-stat-card"><span class="sc-stat-val">${total - confirmed}</span><span class="sc-stat-lbl">待处理</span></div>
      </div>
    </div>
    <div class="sc-table-wrap">
      <div class="sc-table-title">需求明细列表</div>
      <table class="sub-content-table">
        <thead><tr><th>编号</th><th>需求名称</th><th>优先级</th><th>状态</th><th>负责人</th><th>日期</th><th>需求描述</th></tr></thead>
        <tbody>${rowsHtml}</tbody>
      </table>
    </div>`;

  area.style.display = 'block';
  // 隐藏主区各板块
  document.querySelectorAll('.hero,.product-section,.timeline-section,.section-head,.phase-section,.pd-section').forEach(el => el.style.display = 'none');
  area.scrollIntoView({ behavior: 'smooth' });
}

function closeSubContent() {
  const area = document.getElementById('subContentArea');
  area.style.display = 'none';
  area.innerHTML = '';
  // 恢复主区各板块
  document.querySelectorAll('.hero,.product-section,.timeline-section,.section-head,.phase-section,.pd-section').forEach(el => el.style.display = '');
}
```

## 十五、主题切换

```javascript
function toggleTheme() {
  const root = document.documentElement;
  const isDark = root.classList.toggle('dark');
  document.getElementById('themeBtn').textContent = isDark ? '☾' : '☀';
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
}
// 初始化
(function() {
  if (localStorage.getItem('theme') === 'dark') {
    document.documentElement.classList.add('dark');
    document.getElementById('themeBtn').textContent = '☾';
  }
})();
```
